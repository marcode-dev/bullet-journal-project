O Projeto e o Portfólio

O Mark-It nasceu da minha necessidade pessoal por um organizador diário simples, flexível e sem distrações. Desenvolvi este projeto não apenas para resolver minha própria desorganização, mas também como uma peça fundamental para o meu portfólio.

Foi construído utilizando HTML, CSS e JavaScript puros (Vanilla), com foco em manipulação intensiva do DOM, armazenamento local (Local Storage) e interfaces responsivas.

O Método: Bullet Journal

Toda a estrutura do Mark-It (Diário, Notas, Legendas de Cores e ícones de status) é fortemente baseada no método Bullet Journal, criado por Ryder Carroll.

No papel, o Bullet Journal usa símbolos simples (um ponto para tarefas, um círculo para eventos, um traço para notas) para permitir o registro rápido. O Mark-It traz essa mesma filosofia analógica para o mundo digital: você apenas escreve, escolhe o tipo da entrada, e o sistema se encarrega de organizar suas ideias para aquele dia.
